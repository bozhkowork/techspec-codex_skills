# Сборка email-письма

Навык для техспеца, который верстает отдельное письмо по тексту клиента. На вход можно дать текст, скриншоты оформления или старое письмо, которое нужно взять за образец.

## Как установить

Открой нужный проект в Codex и отправь этот запрос в чат.

```text
Установи навык email-letter-workflow из https://github.com/bozhkowork/techspec-codex_skills в текущий проект. Скопируй папку целиком в .agents/skills и проверь, что в ней есть SKILL.md. Если навык уже установлен, покажи различия между версиями перед заменой.
```

В новом чате этого проекта можно написать «Используй навык `email-letter-workflow`. Помоги сверстать письмо по этому тексту и образцу. Начни со сверки материалов».

## Что делает

1. Сверяет тему, прехедер, текст, ссылки и доступные примеры оформления.
2. Уточняет состав подвала, поля подстановки и значения для проверки.
3. Собирает HTML и показывает письмо для правок. По отдельному поручению переносит письмо в черновик на платформе и помогает с тестовой отправкой.

## Что получишь

Готовое HTML-письмо в двух видах — файлом и кодом в чате. При работе в кабинете рассылки можно также получить черновик на платформе и результат согласованной проверки.
