# Сборка клиентского лендинга

Навык для техспеца, который собирает лендинг по материалам клиента. Подходит для новой страницы и переработки существующей.

## Как установить

Открой нужный проект в Codex и отправь этот запрос в чат.

```text
Установи навык landing-page-workflow из https://github.com/bozhkowork/techspec-codex_skills в текущий проект. Скопируй папку целиком в .agents/skills и проверь, что в ней есть SKILL.md. Если навык уже установлен, покажи различия между версиями перед заменой.
```

В новом чате этого проекта можно написать «Используй навык `landing-page-workflow`. Помоги собрать лендинг по этому брифу. Начни со структуры страницы».

## Что делает

1. Уточняет цель страницы, аудиторию и главное действие посетителя.
2. Предлагает структуру и текст по экранам, помогает выбрать оформление.
3. Собирает локальный макет и проверяет его на разных экранах.
4. Готовит исходники или по твоему поручению переносит страницу в редактор платформы, к которому у тебя есть доступ.

## Что получишь

В зависимости от этапа — структуру с текстом, ссылку на локальный предпросмотр, исходники с инструкцией по запуску или редактируемый черновик страницы на выбранной платформе.
