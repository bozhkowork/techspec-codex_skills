# Локальная расшифровка видео и аудио

Навык для работы с записями уроков, вебинаров, интервью и встреч. Распознавание речи происходит на твоём компьютере с помощью Whisper.

## Как установить

Открой нужный локальный проект в Codex и отправь этот запрос в чат.

```text
Установи навык local-video-transcription из https://github.com/bozhkowork/techspec-codex_skills в текущий проект. Скопируй папку целиком в .agents/skills и проверь, что в ней есть SKILL.md. Если навык уже установлен, покажи различия между версиями перед заменой.
```

В новом чате этого проекта можно написать «Используй навык `local-video-transcription`. Расшифруй локально файл `урок.mp4` и сохрани текст с таймкодами».

## Что делает

1. Проверяет, доступны ли Python, FFmpeg и Whisper. Если чего-то не хватает, предлагает, как настроить окружение.
2. Распознаёт речь на исходном языке, сверяет проблемные участки и помечает неразборчивые слова.
3. По твоему поручению готовит на основе записи главы, конспект или другой материал.

## Что получишь

Отдельный файл с полной расшифровкой и таймкодами. Дополнительно можно получить список глав для публикации или конспект записи.
