# Конструктор навыков техспеца

Навык помогает превратить повторяющуюся задачу в инструкцию, которую Codex сможет применять в следующих проектах. Начать можно с примера из работы, брифа или переписки по задаче.

## Как установить

Открой нужный проект в Codex и отправь этот запрос в чат.

```text
Установи навык techspec-skill-builder из https://github.com/bozhkowork/techspec-codex_skills в текущий проект. Скопируй папку целиком в .agents/skills и проверь, что в ней есть SKILL.md. Если навык уже установлен, покажи различия между версиями перед заменой.
```

В новом чате этого проекта можно написать «Используй навык `techspec-skill-builder`. Помоги сделать скилл из моей повторяющейся задачи. Вот как я выполняю её сейчас…»

## Что делает

1. Разбирает пример работы и уточняет, что требуется на входе и каким должен быть результат.
2. Записывает порядок действий, частые исключения и способы проверки. Выносит правила конкретного клиента в настройки проекта, если они меняются от проекта к проекту.
3. Собирает `SKILL.md` и проверяет инструкцию на примерах.

## Что получишь

Папку с новым навыком, файл `SKILL.md` и пример запроса для первого запуска. При необходимости в папке будут дополнительные материалы, которые нужны для работы навыка.
